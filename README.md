- **交付节点**  
  3 周内完成原型联调， 

---

## 2 技术方案总览
| 维度 | 说明 |
|---|---|
| **自由度** | Pitch 轴 + Yaw 轴（两轴联动） |
| **控制链路** | 上位机（人物识别&跟踪规划） ↔ 485协议通信 ↔ 下位机（STM32F407VET） |
| **执行机构** | 大扭矩电机（工作电压 48 V） 48v舵机（开火，485 A/B相拉升至5v） |
| **反馈保护** | 限位器+12v降压模块 |

---

## 3 关键技术点

### 3.1 上下位机联调
- **协议设计**：自定义 CAN 扩展帧（29-bit ID），Payload 8 byte  
  - `0x1xx`：目标角度  
  - `0x2xx`：实时角度回传  
  - `0x3xx`：故障/限位标志
- **调试工具**  
  - PC 端：上位机系列电机助手+串口助手  
  - MCU 端： 标准库 + FreeRTOS

### 3.2 舵机接口改造
- **问题**：舵机 485控制线默认 3.3 V 逻辑，但驱动器要求 5 V。  
- **解决**：TTL转485模块升压 + 上拉 5 V，

### 3.3 限位器电平转换
- **场景**：机械限位开关为 5 V 开漏输出，主控 IO 仅 3.3 V 容忍。  
- **方案**：  
  1. 限位器 → 电源降压5 V

## 6 实习心得
- **嵌入式“三分代码七分调”**：逻辑正确≠系统可靠，真实工况永远比实验室严苛。  
- **跨部门沟通**：与视觉组约定“角度-像素”映射表，深刻体会接口文档的重要性。  
- **安全意识**：万用表 测分电架电流 防止烧毁电路，电熔绞 飞线
- **部门协同**： 机械 上位机 推拉流 每一个部分都紧密相关 调试
